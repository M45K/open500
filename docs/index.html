What is it?

Open500 is a small loader added to the official MPC500 operating system. Once it is installed, add-ons are just WAV files: you load them from the CompactFlash like any sample, and they show up in the OTHER menu as native pages — same fonts, same cursor, same wheel and DO IT / CANCEL as the original OS.

Delete the add-on sample and it is gone. Reflash the original OS and your MPC is exactly as it came from Akai.

Auto Chop

Chop a loop by BPM and lay the slices on the pads, in one step.

BREAK01 B 93.0 N 8 P 1

Pick the sample with the wheel, set the tempo (B), the number of slices (N) and the first pad (P), press DO IT. The slices are new samples, assigned to the pads of the current program. Shortcut: SHIFT+STOP.

Install

Once. Takes about five minutes. You need a CompactFlash card and a computer.

  1. Get the official OS 1.31

    Download the MPC500 OS 1.31 from Akai Professional and unzip it: you get mpc500.bin.

    Download OS 1.31 from Akai (288 KB)

  2. Add Open500 to it

    Drop mpc500.bin here. It is patched in your browser: nothing is uploaded.

    Drop mpc500.bin here or click to choose it

      We never distribute Akai's firmware: this page only adds the Open500 loader (1.3 KB of our own code) to the file you provide, checks that it is the untouched OS 1.31, and recomputes the checksum. The result is identical, byte for byte, to the firmware we tested.

    • Flash it

      Copy MPC500.bin to the root of the CompactFlash card and insert it in the MPC500. Hold SHIFT while you switch the MPC on, then press REC when the screen asks for it. Wait for the update to finish.

    • Load the add-ons

      Copy HUB.WAV and the add-ons (e.g. CHOPAGE.WAV) to the card. On the MPC, LOAD HUB.WAV first (the screen shows LOADED hub), then the add-ons (LOADED <name>).

      Open them from MODE → OTHER: the add-ons are listed after Version. Select one, press DO IT. CANCEL goes back.

    Add-ons live in memory like samples: after switching the MPC off, load HUB.WAV and the add-ons again (tip: keep them in the same folder as your project).

    Safety & going back

    • Open500 does not touch the bootloader. If anything goes wrong, the MPC can always be updated again.
    • To remove it: flash the original mpc500.bin (OS 1.31) the same way (SHIFT at power on, then REC).
    • Open500 reserves the last 256 KB of sample memory for the add-ons.
    • Messages on the second line: NO FREE SLOT (4 add-ons already loaded), BAD (damaged WAV), LOW MEM: ADDONS! (sample memory almost full). SHIFT+ERASE reloads the add-on manager.

    FAQ

    Does it work on the MPC1000 / MPC2500?

    Not yet. Open500 is built on a detailed study of the MPC500 OS 1.31; other models run different software.

    Does it change how my MPC500 works?

    No. Without add-ons loaded, the OS behaves like the original 1.31 — the only difference is 256 KB less sample memory, reserved for add-ons. Your programs, samples and sequences are not affected.

    Why do I have to provide the OS file myself?

    Because the operating system belongs to Akai. Open500 only publishes its own code, and your browser combines the two on your computer.

    Can I write my own add-on?

    Yes, that is the idea. The add-on SDK (Python, with an emulator to test add-ons before trying them on the MPC) will be documented in the repository.

    I have an idea for an add-on

    Great — open an issue in the repository and describe it.
